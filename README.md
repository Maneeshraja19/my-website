**https://maneeshraja19.github.io/my-website/**

## Local Preview

Open `index.html` in a browser, or run a local server:

```bash
# Python
python -m http.server 8080

# Node (if npx is available)
npx serve .
```

Then visit `http://localhost:8080`.

## Deploy to GitHub Pages

1. Push this repo to GitHub (`Maneeshraja19/my-website`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` (or `master`) and folder `/ (root)`.
5. Save — the site goes live in 1–2 minutes.
